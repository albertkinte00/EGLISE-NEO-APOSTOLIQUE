## ⚡ PROBLÈMES COURANTS

**"CORS blocked"** → Ajouter URL dans Supabase Settings → API → CORS Origins

**"Unauthorized"** → Vérifier credentials correctes dans les fichiers

**"Table not found"** → Vérifier SQL complètement exécuté dans Supabase

**"Data not loading"** → Vérifier F12 console pour erreurs API
