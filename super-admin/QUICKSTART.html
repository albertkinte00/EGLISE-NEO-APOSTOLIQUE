Installation (5 min)

1 Télécharger les fichiers
Récupérez le dossier `super-admin/` depuis GitHub ou FTP
2 Configurer le fichier config.js
Modifier les URLs Supabase et l'email administrateur
SUPER_ADMIN_CONFIG = { APP_NAME: 'Votre App', AUTH: { SUPER_ADMIN_EMAIL: 'votre@email.com' } }
3 Personnaliser la clé secrète
Modifier la clé dans `login.html` (ligne ~230)
Utiliser une clé forte et unique (min. 16 caractères)
4 Tester la connexion
Accéder à `login.html` et se connecter avec vos identifiants
5 Activer les sauvegardes
Aller à Paramètres → Sauvegardes Programmées

Première Connexion

Lors de votre première visite:

  1. Email: L'adresse configurée dans config.js
  2. Mot de passe: Votre mot de passe personnel
  3. Clé Secrète: La clé définie dans login.html
Connexion réussie ! Vous êtes maintenant connecté au Super Admin

Tâches Courantes

Créer un nouvel utilisateur

  1. Aller à Utilisateurs
  2. Cliquer Nouvel Utilisateur
  3. Remplir les informations
  4. Sélectionner le rôle
  5. Cliquer Enregistrer

Ajouter une communauté

  1. Aller à Communautés
  2. Cliquer Nouvelle Communauté
  3. Remplir les informations de base
  4. Positionner sur la carte
  5. Ajouter horaires et contacts
  6. Cliquer Enregistrer

Faire une sauvegarde

  1. Aller à Sauvegardes & Restauration
  2. Cliquer Nouvelle Sauvegarde
  3. Attendre la fin (2-5 min)
  4. Télécharger ou archiver le fichier

Recommandations de Sécurité

  • Utiliser HTTPS (SSL/TLS)
  • Mot de passe fort (min. 12 caractères)
  • Activer 2FA
  • Changer régulièrement la clé secrète
  • Sauvegardes régulières
  • Monitorer les logs d'activité
  • Forcer l'expiration de session
  • Ne jamais partager les identifiants
Important : Cet accès est réservé au responsable principal seulement.

Dépannage Rapide

❌ "Impossible de se connecter"

  • Vérifier l'email dans config.js
  • Vérifier la clé secrète (casse sensible)
  • Vider le cache du navigateur
  • Essayer un autre navigateur

❌ "Page 404 - Non trouvée"

  • Vérifier que le dossier `super-admin/` existe
  • Vérifier les permissions d'accès (644/755)
  • Vérifier l'URL (https, pas http)

❌ "Erreur Supabase"

  • Vérifier l'URL du projet Supabase
  • Vérifier la clé ANON_KEY
  • Vérifier la disponibilité de Supabase
